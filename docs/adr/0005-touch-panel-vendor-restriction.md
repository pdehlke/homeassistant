# Restrict TSW-752 replacement candidates to Shelly Wall Display and Sonoff NSPanel Pro

Generic unbranded Android wall panels are excluded as touch panel replacements, regardless of
price. The recurring community-reported failure mode is a panel that never receives an Android OS
update past version 8 or 9, breaking Home Assistant's companion app or dashboard rendering within
a year or two; both named vendors have a track record of shipping updates, which outweighs raw
spec-sheet comparison. See [docs/crestron/crestron-strategy.md](../crestron/crestron-strategy.md).
